# Contributing to Valo projects

- Each repository has its own CONTRIBUTING.md with the setup and checks, start there. For the hub it is
  [valo/CONTRIBUTING.md](https://github.com/valo-home/valo/blob/main/CONTRIBUTING.md).
- Search existing issues before opening a new one. For bugs include the version, steps and logs without passwords.
- For bigger changes open an issue first to agree on the approach.
- Be kind, see the [code of conduct](CODE_OF_CONDUCT.md).
- Security problems are reported privately, see [SECURITY.md](SECURITY.md).
- Contributions are licensed under the Apache License 2.0.
