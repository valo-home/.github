# Code of conduct

Valo follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, welcome newcomers, criticise ideas and not people, no harassment,
discrimination or personal attacks. Maintainers may remove comments, commits and contributors that break
these rules.

Report problems privately to the maintainers through a GitHub private vulnerability report in
[valo-home/valo](https://github.com/valo-home/valo/security/advisories/new) marked "conduct", or by a
direct message to an organisation owner. Reports are handled confidentially.
