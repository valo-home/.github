# Valo

A local smart home hub: Zigbee, MQTT and IP cameras in one interface, automations, dashboards and extensions. Runs on a small computer at home, no cloud needed.

```
curl -fsSL https://raw.githubusercontent.com/valo-home/valo/main/install.sh | sudo bash
```

| Repository | What is inside |
| --- | --- |
| [valo](https://github.com/valo-home/valo) | the hub: core, web interface, official extensions, documentation, installer |
| [extension-template](https://github.com/valo-home/extension-template) | a starting point for your own extension |
| [app](https://github.com/valo-home/app) | the mobile app |
